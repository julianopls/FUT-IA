## 📖 Sobre o projeto

O **FUT-IA** é um projeto de desenvolvimento de jogos inspirado no futebol de rua, com foco em jogabilidade, interatividade e diversão.

A proposta é oferecer uma experiência acessível, com partidas dinâmicas, controles intuitivos e possibilidades de expansão para novos modos de jogo.

O projeto também serve como oportunidade para desenvolver habilidades em programação, lógica de jogos, criação de interfaces e implementação de novas funcionalidades.

## 🎮 Funcionalidades

- ⚽ Partidas de futebol com temática de rua.
- 🕹️ Controles interativos e mecânicas de jogo.
- 🎬 Sistema de replay das jogadas.
- ⏭️ Opção para pular a reprodução do replay.
- 🌐 Desenvolvimento de funcionalidades para partidas online.
- 👥 Planejamento de salas com equipes e espectadores.
- 🎨 Interface desenvolvida para proporcionar uma experiência intuitiva.

> **Nota:** a disponibilidade de cada funcionalidade depende da versão atual do projeto.

## 🛠️ Tecnologias

O projeto utiliza tecnologias de desenvolvimento web, conforme a implementação presente no repositório.

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilos, layout e identidade visual.
- **JavaScript** — lógica, interações e mecânicas do jogo.

## 🚀 Como executar o projeto

### Pré-requisitos

- Navegador atualizado.
- Git instalado para clonar o repositório.

### Instalação

**1. Clone o repositório:**

```bash
git clone https://github.com/julianopls/FUT-IA.git
```

**2. Acesse a pasta:**

```bash
cd FUT-IA
```

**3. Execute o projeto:**

Se a versão utilizar HTML, CSS e JavaScript sem dependências de servidor, abra o arquivo `index.html` no navegador.

Caso existam dependências adicionais, consulte os arquivos de configuração do projeto para seguir o procedimento correto.
